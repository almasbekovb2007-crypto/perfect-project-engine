# ОРТ Академия

Веб-платформа для подготовки к Общереспубликанскому тестированию (ОРТ). Ученики могут проходить курсы и тесты, отслеживать прогресс и работать над ошибками; преподаватели управляют учебными материалами, а администраторы — пользователями и заявками преподавателей.

## Возможности

- Регистрация и вход, профиль пользователя и настройки приватности.
- Курсы, уроки и тесты с автоматической проверкой.
- Панель ученика со статистикой прогресса и списком ошибок.
- ИИ-помощник для вопросов по подготовке.
- Рейтинг учеников.
- Кабинет преподавателя для управления курсами, уроками и тестами.
- Панель администратора и обработка заявок преподавателей.

## Технологии

- React 19, TypeScript и Vite.
- TanStack Start и TanStack Router.
- Supabase для аутентификации и данных.
- Tailwind CSS и компоненты Radix UI.

## Требования

- Node.js и npm (либо Bun).
- Проект Supabase с настроенными таблицами и миграциями из `supabase/migrations`.

## Запуск локально

1. Установите зависимости:

   ```bash
   npm install
   ```

   Или, если используете Bun:

   ```bash
   bun install
   ```

2. Создайте файл `.env` в корне проекта и укажите параметры Supabase:

   ```dotenv
   VITE_SUPABASE_URL=https://<project-ref>.supabase.co
   VITE_SUPABASE_ANON_KEY=<supabase-anon-key>
   ```

3. Запустите сервер разработки:

   ```bash
   npm run dev
   ```

   Либо `bun run dev`. Адрес локального сервера Vite будет показан в терминале.

### ИИ-помощник

Для работы серверной функции ИИ задайте переменную `AI_API_KEY` в окружении сервера. При необходимости можно указать `AI_BASE_URL` и `AI_MODEL`; по умолчанию используются API-адрес OpenAI и модель `gpt-4o-mini`. Не добавляйте секретный API-ключ в переменные `VITE_*`: они доступны клиентскому коду.

## Структура проекта

- `src/routes` — страницы и файловые маршруты приложения.
- `src/components` — общие компоненты интерфейса.
- `src/lib` — контексты, утилиты и серверные функции.
- `src/integrations/supabase` — клиент и типы Supabase.
- `supabase/migrations` — миграции схемы базы данных.

Маршруты создаются на основе файлов в `src/routes`. Дополнительные соглашения описаны в [`src/routes/README.md`](src/routes/README.md). Файл `src/routeTree.gen.ts` генерируется автоматически — не редактируйте его вручную.
